# Принципы создания формы контракта #


1. ## Размещение форм контрактов.

	Форма контракта должна быть размещена в папке [/GrpcWinForms/Objects/Contracts/ContractViews](/GrpcWinForms/Objects/Contracts/Forms/ContractViews). 
	Название формы должно соответствовать полю DocumentType_Form в справочнике DocumentTypes. 
	Например, если в справочнике DocumentTypes есть тип документа "Стандартная продажа" со значением в поле DocumentType_Form = ContractSaleStandartForm, 
	то форма контракта должна называться также.
 
2.	## Описание формы.

	Тип формы должен наследоваться от класса **ContractFormClass**.
	Данный класс уже имеет:

	Конструкторы:
	- **ContractFormClass()**;
	- **ContractFormClass(Contract contract)**.

	Свойства:
	- **ViewMode** - **enum ViewMode**, указывающий в каком режиме запускается форма. режим показа: ViewMode.View - режим показа, ViewMode.Edit - режим редактирования, ViewMode.Edit - режим добавления;
	- **Contract** - объект типа **Contract**, содержащий контракт для посмотра или редакитирования 
	- будет расширяться.

	События:
	- **public event EventHandler\<Contract> ContractChanged** - на данное событие подписана форма ContractsForm, которая при возкновении этого события обновляет данные контракта в форме;
	- будeт расширяться.

	Методы: 
	- **Show()** - метод для показа формы;
	- **protected virtual void OnContractChanged(Contract contract)** - Шаблон для безопасного поднятия события в производных классах;
	- будет расширяться.
