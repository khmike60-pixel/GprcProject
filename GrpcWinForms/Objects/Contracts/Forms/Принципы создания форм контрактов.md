# Принципы создания формы контракта #

1. ** Размещение форм контрактов**: 
	Форма контракта должна быть размещена в папке GrpcWinForms/Objects/Contracts/Forms/FormsOfContracts (переделать наименование). 
	Название формы должно соответствовать типу документа в справочнике DocumentTypes. 
	Например, если в справочнике DocumentTypes есть тип документа "Стандартная продажа", 
	то форма контракта должна называться ContractSaleStandartForm.
2. **Тип формы**: 
	Тип формы должен быть ContractFormClass. 
	Данный класс уже имеет свойство ContractId и конструктор ContractFormClass(int contractId).
